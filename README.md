# Starmap

An interactive Three.js starmap with procedural stars and planetary-system controls.

## Start here

[Open main build](https://actiondaveinri.github.io/starmap/starmap_001_frz_2.html) · [Choose a version](https://actiondaveinri.github.io/starmap/index.html) · [All projects](https://github.com/ActionDaveInRI/spaceship/blob/main/PROJECTS.md)

One preserved build, with a clear launch point.

## Run it

Open the build in a modern browser with internet access for Three.js and OrbitControls. Use the in-page controls to regenerate stars and explore the scene.
